Desenvolvimento Web — Projeto de Abas 1° Semestre.

Sobre o projeto

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Web do 1º semestre.
A proposta consiste na criação de uma interface com sistema de abas (tabs), utilizando apenas HTML e CSS, organizando diferentes conteúdos em seções dinâmicas dentro da mesma página.

O foco é praticar estruturação semântica, estilização e organização visual, simulando componentes comuns em aplicações web reais.

---

Objetivos de aprendizagem:
- Aplicar conceitos básicos de HTML semântico
- Utilizar CSS para layout, posicionamento e estilização
- Criar navegação por abas interativas
- Melhorar organização de código e separação de responsabilidades
- Desenvolver noções de usabilidade e experiência do usuário

---

Tecnologias utilizadas
HTML5
CSS3

---
Funcionalidades
- Navegação por abas
- Exibição dinâmica de conteúdo
- Layout responsivo
- Estrutura simples e intuitiva
